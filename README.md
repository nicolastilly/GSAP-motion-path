# Exercice Motion path avec GSAP

Présentation de l'exercie de micro animation avec GSAP : une forme suit un tracé.

Objectifs de l'exercice :

- Utiliser motion path de GSAP
- Dessiner des tracés et une forme qui le suivra
- Définir une palette de couleurs pour les dessins

L'exercice doit également utiliser la librairie swipe.js afin de produire une "collection" de micro animations.
